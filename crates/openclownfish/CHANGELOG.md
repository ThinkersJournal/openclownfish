# Changelog

Changes to `openclownfish`. The repository `CHANGELOG.md` also covers the unpublished `openclownfish-clc`.

## 0.1.5

First release with content: the crates.io versions before this (0.0.0) only reserved the name. The safe API: `Runtime`, `Platform`, `Device`, `Context`, `Queue`, `Buffer`, `Program`, `Kernel` (with `unsafe Queue::launch`), `Event`, and the `icd` re-export, over `openclownfish-sys`. Adds a README stating where it has been tested, `rust-version` 1.88 and this changelog. Earlier 0.0.x to 0.1.4 versions were never published; their history is in the repository `CHANGELOG.md`.
