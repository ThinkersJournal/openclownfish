Tooling traps seen here: the Bash tool collapses doubled backslashes (a `\\n` meant for Rust became a raw newline inside a string literal, found only on a later read), so write Rust with the Write/Edit tools or build backslashes with `chr(92)`; a bash heredoc containing an apostrophe can fail to parse, use Write; a Python `open(p,'w')` before the edit function runs truncates the file when the edit raises (compute first, write after); `cargo test --workspace` exceeds the 2 minute Bash limit, so run it in the background and commit in a separate call; `git add -N .` marks the untracked `supertool` in the primary, undo with `git reset supertool`.
